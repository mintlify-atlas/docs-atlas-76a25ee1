The Polymarket Copy Trading Bot is a fully operational Node.js runtime that automates trading on Polymarket's recurring 5-minute BTC Up/Down markets. It includes both a dual-sided arbitrage engine and a configurable copy-trading system for following target wallets — with real CLOB authentication, on-chain Polygon transactions, WebSocket order-book tracking, and built-in risk controls.

## Two trading modes

The bot ships with two distinct operating modes selected via the `TRADING_MODE` environment variable.

<Steps>
  <Step title="Choose your mode">
    Set `TRADING_MODE=arb` to run the BTC Up/Down arbitrage engine, or `TRADING_MODE=copy` to run the dedicated buy-only copy trader.
  </Step>
  <Step title="Configure your wallet">
    Set `PRIVATE_KEY` and `PROXY_WALLET` in your `.env` file. These are required for both modes.
  </Step>
  <Step title="Set risk limits">
    Configure `MAX_SPEND_PER_MARKET`, `MAX_LOSS_PER_HOUR_USDC`, and copy-trading caps before your first run.
  </Step>
  <Step title="Run the bot">
    Execute `npm start` for arbitrage mode or `npm run copy` for copy-trading mode. Use `COPY_DRY_RUN=true` to test copy logic without placing real orders.
  </Step>
</Steps>
