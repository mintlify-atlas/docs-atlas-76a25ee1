---
title: "Quickstart: set up and launch the copy trading bot"
description: "Learn how to install, configure, and launch the Polymarket Copy Trading Bot for arbitrage or copy trading on Polygon in four steps."
---

This guide walks you through installing the bot, creating your environment file, filling in the minimum required settings, and running your first session. The whole process takes under five minutes assuming you already have Node.js 18+ and your Polymarket wallet details available. If you need to verify prerequisites first, see the [requirements](/requirements) page.

<Steps>
  <Step title="Install dependencies">
    Clone or download the repository, then install Node.js dependencies using npm. The repository includes a `package-lock.json`, so a standard install is all that is needed.

    ```bash
    npm install
    ```
  </Step>

  <Step title="Copy the environment file">
    Create your local `.env` file from the provided example. All configuration for the bot lives in this file.

    <CodeGroup>

    ```bash bash
    cp .env.example .env
    ```

    ```powershell PowerShell
    Copy-Item .env.example .env
    ```

    </CodeGroup>

    Open `.env` in your editor. The file contains inline comments that explain each setting. Read them before proceeding.
  </Step>

  <Step title="Configure minimum required settings">
    Three values are required for almost every real run. Set them in your `.env` file before starting the bot.

    ```bash .env
    # Your Polygon EOA private key — controls approvals and order signing
    PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE

    # The Polymarket proxy wallet address associated with your account
    PROXY_WALLET=0xYOUR_PROXY_WALLET_HERE

    # Polygon RPC endpoint — strongly recommended to use a private provider
    POLYGON_RPC=https://polygon-rpc.com
    ```

    The CLOB API credentials (`POLY_API_KEY`, `POLY_API_SECRET`, `POLY_API_PASSPHRASE`) can be left blank on first run. The bot derives valid credentials automatically from your signer.

    For copy trading, also set `COPY_TARGETS` to a comma-separated list of target Polymarket proxy wallet addresses.
  </Step>

  <Step title="Choose a trading mode and run">
    The `TRADING_MODE` variable in `.env` controls which strategy runs when you execute `npm start`. You can also override it per-run using the named npm scripts.

    **Arbitrage mode** (default):

    <CodeGroup>

    ```bash npm start
    npm start
    ```

    ```bash npm run arb
    npm run arb
    ```

    </CodeGroup>

    **Copy trading mode**:

    <CodeGroup>

    ```bash npm run copy
    npm run copy
    ```

    ```bash dedicated entrypoint
    node src/copy/index.js
    ```

    </CodeGroup>

    Use `node src/copy/index.js` when you want to run the dedicated copy trading engine on its own, without the BTC arbitrage lifecycle.
  </Step>
</Steps>

<Tip>
  Start copy trading with `COPY_DRY_RUN=true` in your `.env` file. In dry-run mode the bot logs every action it would take but does not submit any real orders. This lets you verify that target wallet detection, sizing, and filters are working correctly before committing funds.
</Tip>

<Warning>
  On your first real-money run, use conservative spend limits. Set a small `MAX_SPEND_PER_MARKET` for arbitrage, or low `COPY_MAX_USDC_PER_TRADE` and `COPY_MAX_USDC_TOTAL` caps for copy trading. Review `bot.log` after a short session before increasing limits.
</Warning>
